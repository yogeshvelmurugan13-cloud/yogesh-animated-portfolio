# Yogesh Animated Portfolio

Modern React + Vite portfolio built from the public content on Yogesh's Crio portfolio.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Customize
- Replace placeholder GitHub links in `src/main.jsx` with each project's real repository/live URL.
- Update the email address if needed.
- Add your resume as `public/Yogesh-Resume.pdf` and add a resume button if desired.
